### 0.1 题材：野餐（2026-10-29）

原来的果园题材和火车玩法对不上：水果在玩法里已经没有了，果园里跑火车没有理由，大炮打毛毛虫比例也怪（owner："你不必强行的来迎合当前的设定……独立设定一个合适的主题"）。改成野餐桌：

- **场地**：草坪中间铺一块**黄白格子野餐布**，略斜着放，四周露出草地和雏菊（2026-10-30 改，§16.18；原先定的是不铺布直接放草坪上，因为红白格子会把红火车和深色虫子吃掉，换成淡黄格子后虫子反而最清楚。`?ground=lawn` 还能切回草坪版对比）。布边一圈是立体的草和雏菊，再往外是用同样的草烘焙出来的草皮贴图。中间一个薄荷绿**蛋糕托盘**上放着粉色淋面的**生日蛋糕**（大家要抢的东西，纯装饰），外面一圈蜂蜜色**木头玩具轨道**；布上随手放一块红格子餐巾（带勺子）和两颗草莓，再外面隔一圈草地是一圈圆形的**棉花糖立柱 + 威化饼横栏**围栏（就是"城墙"，被啃一点掉一块）。周围草地上点缀雏菊和大叶子，不再摆野餐篮和盘子（2026-10-29 按定调图重做，§16.6）。
- **英雄是玩具**：锡兵、发条机器人、毛绒恐龙（§7.2），坐在玩具火车头里，火车打**彩色果冻豆**。
- **敌人是虫子**：蚂蚁、苍蝇、甲虫、蜗牛、霉菌团，Boss 蝗虫王（§8）。玩具和虫子尺度一致，这是换题材的主要理由。
- **局外"玩具箱"**：原来的"村落"页，建筑是加固围栏和储钱罐。
- 代码里的 id 没改（`farmer` / `beekeeper` / `chef`、`caterpillar` / `crow`、`village`、存档前缀 `fruit-fort:`），只换了模型、文案和图标，免得动存档和统计。

### 0.2 题材改为科幻虫群（2026-10-31 立项，2026-11-02 转正）

owner 觉得野餐风受众太窄：粉嫩的玩具野餐看上去像给低龄、偏女性玩家做的，和"加属性、刷波次"的中核玩法以及门户站的主力人群（男性，十几到三十出头）都对不上。重新立项比较了五个题材：A 科幻轨道炮车对外星虫群、B 末日装甲列车对僵尸、C 奇幻、D 玩具兵、E 西部。选了 **A**；B 留作备选，僵尸需要骨骼动画，成本更高。

- **画风**：明亮、饱和、风格化的 3D，皇室战争、荒野乱斗那一路。不走写实暗黑。
- **配色**：
  - 我方：**青白**（白色机身、青色发光）
  - 虫子：**深紫**，弱点发**黄橙光**
  - 地面：先定的是橙红沙漠，2026-10-31 改成**浅冰蓝**（冻土、冰面）。owner 觉得橙黄太深太重，浅蓝下紫色虫子反而更醒目。`?ground=sand` 还能切回沙漠对比。
  
  定调图见 `docs/art/scifi_r1/README.md`。
- **场景对应**：
  - 蛋糕 → 六边形底座上的能源**反应堆**
  - 木头轨道 → **磁悬浮轨道**（钢轨，带青色灯条）
  - 小火车 → **悬浮轨道炮车**（双管炮塔，后甲板站英雄，尾部电容桅杆）
  - 棉花糖围栏 → **枪灰色桩子加青色能量护盾板**
  - 果冻豆 → **青白能量弹**
  - 虫子 → 紫黑外星虫，背上的弱点发光
- **引擎样片**：URL 加 `?theme=scifi` 就切到科幻场景，玩法完全一样。实现在：
  - `src/view/theme.ts`：开关
  - `src/view/scifi.ts`：冰原和岩壁、反应塔、磁轨、炮车、士兵英雄
  - `models.ts`：护盾墙（`makeFence` 的科幻分支和 `shieldPanels`）
  - `swarm.ts`：科幻虫子
  - `units.ts` / `main.ts`：弹道和命中火花
  
  野餐版保持原样。截图：`docs/art/scifi_r1/engine_frost_{d,p}.png` 是冰蓝地面，`engine_{d,p,l}.png` 是沙漠地面。

- **我方配色（2026-11-02）**：owner 先说英雄和坦克“糊成一坨”，改浅钢灰后又“变成白色”，换橙色上半身仍觉得奇怪。独立评估后结论是问题不在英雄，而在三者的分工：
  - 坦克车身是深钢蓝（`0x3e4c62`），在青光下近乎黑，游戏视角里看不见；概念图里坦克本是白的，和反应堆的白壳同一套。
  - 基地的青色辉光铺满轨道和反应堆，场上没有中性色垫底：浅色物体被染青发白，深色物体又和地面混成一片。
  - 大块饱和橙压在黑车上，成了全场最抢眼的东西，像个交通锥；概念图里橙色只做镶边。
  - 定下的方案（概念图的白 + 枪灰 + 小块橙 + 青色只做灯和描线）：
    - 坦克（`tank.ts`）车身浅白灰 `0xc9d0da`、金属度 0.3，下层板用基地的枪灰 `0x4a5462`。
    - 基地（`scifi.ts`）辉光约降到四成：反应堆描边 0.55、光套 0.2、信标 1.4，轨道导线 0.35、灯块 0.45。能量柱、护盾墙、地上的水晶不变。
    - 英雄（`troopers.ts`）身体深枪灰 `0x3a4352`，靠明暗从白车上分出来；头盔和肩甲（俯视时露出舱口的就是这块）用暖色，是全场唯一的暖色点，一眼找到玩家：陆战队员橙、工程师琥珀、重装红橙。面罩一律青色，紫色留给虫子。英雄在舱口里放大到 0.9 倍。
  - 后备也跟着改了（2026-11-03）：加载失败时的头像 SVG（`icons.ts` `HERO_ICON`）和找不到 GLB 时的代码模型（`scifi.ts` `TROOPERS`）用同一套颜色，代码模型的肩甲也换成头盔色。
  - A16 实测（2026-11-03，新配色加按距离的步态）：第 1–2 波 58 fps，p95 16.8 ms，和改之前一样。
- **步态跟着移动速度（2026-11-02）**：腿原来按时钟摆，快虫滑步、慢虫原地踏步。现在腿的相位按实际走过的距离推进：`horde.ts` 的 `strideOf` 按每种模型腿的长度（关节到脚的中位数）和摆幅 `SWING` 算出一个相位周期走多远，`units.ts` 每帧用位移除以它；上限约每秒 5 步（`MAX_STEP`），再快腿就糊了。飞虫和正在啃咬的虫照旧按时钟。
