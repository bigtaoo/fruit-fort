# Tripo 第 1 轮：蚂蚁

2026-10-29。owner 的 Tripo 是免费账号（开始 50 积分，后来多出一笔赠送，变成 140），在 Chrome 里用 Tripo Studio 网页版生成。`~/.vibe/` 里那两个 Tripo API key 余额都是 0，网页积分和 API 积分是分开算的，所以 API 用不了。

- 输入：`ant_in.jpg`，由 `chars_r1/ant.png` 裁成方图，768×768。
- 模式：
  - "智能网格 / 干净拓扑"，就是低模版。正常要 100 积分，免费账号可以试用 2 次，这次用掉了 1 次。
  - "最高质量"要 55 积分，比账号里的余额还多。
- 拓扑设置：四边面，面数默认 5000（可以在 500～25000 之间调），也可以选三角面。
- 结果：`ant_mesh.png` 是 Tripo 视口里的白模截图。四边面，5799 个面，5311 个顶点，没有贴图。贴图要再花 20 积分。
- 任务页：https://studio.tripo3d.ai/zh/workspace/generate/ce8fce03-e938-4dcf-8f6a-829867d9f0b8

## 发现

- **形状很好**：
  - 三段身子、6 条腿、两根触角、眼睛和笑脸都在，比例和设定图一样；
  - 远侧那条被挡住的腿也补出来了；
  - 布线是规整的四边面，可以直接减面。
- **面数超了**：5799 个四边面，大约 1.16 万个三角面，§16.2 定的是每只虫子不超过 1500 面。下次把面数滑块拉到最低（500～1500），并选三角面。
- **一整块，没拆开**：腿和身体连在一起，而代码里要让腿单独摆动。拆部件有两种办法：
  - Tripo 的"部件拆分"，可能要付费；
  - 自己在 Blender 里按腿切开。
- **不要 Tripo 的贴图**：我们的风格是纯色加柔和明暗，在代码里按部件上色就行，正好省下那 20 积分。
- **智能网格导出要订阅**：点导出直接弹出订阅窗口（每月 €12 或 €41），这个模型下载不了。

## 第 2 次：高精度 H2.5，可以导出

为了找免费账号能导出的模式，换成"高精度模型"，AI 模型选 **H2.5 经典版**，几何设置：三角面、面数 1500、关掉贴图。

- 花费：15 积分（开贴图是 25）。账号余额 140 → 125。
- 结果：三角面，1500 面，752 个顶点。
- 导出：导出按钮上没有皇冠，GLB 直接下载下来了，约等 1 分钟。弹窗上写"剩余 5 次"，导完变 4 次，所以**免费账号能导出几次**（多久重置还不清楚）。
- 文件：`ant_h25.glb`，28 KB。一个 mesh，只有位置和法线，没有材质和贴图；高 0.84，宽 ±0.39、长 ±0.5，脚踩在 y=0。可以直接 `GLTFLoader` 读进来再按比例缩放。
- 任务页：https://studio.tripo3d.ai/zh/workspace/generate/e40c7192-21cb-449b-b6c2-29afd58a0892

### 发现

- **H2.5 比智能网格粗**：头是一个大圆球，脸上的眼睛和笑脸糊成了几个凹坑，腿是细管子。远看（手机上虫子约 46 像素）够用，近看不行。
- **1500 面正好卡在 §16.2 的上限**，不用再减面。
- **还是一整块**：腿没有拆开。要腿单独动，得在 Blender 里切，或者试一次"分部件生成"（订阅专享，可以试用 1 次）。
- **积分账**：125 积分，按 15 一个，还能出 8 个 H2.5 白模；但导出只剩 4 次，导出次数才是瓶颈。剩下的角色要先挑最需要模型的（火车、锡兵、蛋糕可能用代码拼更好）。
