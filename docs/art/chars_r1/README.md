# 角色第 1 轮：火车、锡兵、蚂蚁的设定图

2026-10-29。风格已定（`style_r4/b_marsh.png`，见 design §16.1）。这轮用图生图（`scripts/art/edit_image.sh`），拿 `base.png`（就是 `b_marsh.png`）当底，让它"用一模一样的画风"单独画一个角色，放在纯白背景上，四分之三俯视（`*.txt`）。这些图是给 Tripo 图生 3D 用的。`phone.png` 是缩到 0.09 倍的样子，和角色在竖屏手机上差不多大。

| 文件 | 结果 |
|---|---|
| `train.png` | **能用**。红车身、黑烟囱、黑车顶，轮子是浅木色，和场景图里的车头一致。驾驶室是空的，正好放英雄。车身是几个分开的大块（锅炉、驾驶室、底盘），建模好拆 |
| `soldier.png` | **能用**。黑高帽、红上衣、白色交叉肩带、金肩章、蓝裤子、黑靴。手臂和身体之间留了空隙，四肢都分得开，绑骨骼不费事。缩小后黑帽仍是最好认的地方 |
| `ant.png` | **能用**。深棕红，三段（头、细腰、大肚子），黑色细腿，大眼睛。离木色、饼干色都远。远侧的一条腿被身子挡住了，正面看只有 5 条半，Tripo 可能补不全，建模时检查一下 |

## 发现

- **一次就成**：三张都是白底、只有一个角色、画风和定调图一致，没有多画东西。用定调图当底图做图生图，比文生图稳得多，后面的角色都照这个办法。
- **缩到手机大小都认得出**：火车靠红色和黑烟囱，锡兵靠黑高帽，蚂蚁靠深红的圆身子和白眼睛。
- **要留意的地方**：
  - 蚂蚁的腿是又细又黑的线，手机上只剩几个像素。游戏里可以把腿加粗一些，或者干脆只靠身子的轮廓来认。
  - 火车车轮是木色，和轨道同色，在轨道上会糊在一起。建模后可以把轮子换成深色或金色。
  - 画面是 1152×896 的横图，角色只占中间一块。喂给 Tripo 前可以先裁成方图。
- **下一步**：
  - 把三张图喂给 Tripo 出模型，看拓扑和面数能不能用在低端机上。
  - 用同一个提示词模板出剩下的 P0 角色：甲虫、蜗牛、蛋糕，以及其他英雄。
