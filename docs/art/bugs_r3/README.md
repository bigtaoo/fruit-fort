# 虫群重设计（第三轮概念）

2026-11-02。旧虫子（`scifi_r2/e_bugs.png`）有三个问题：

- 原设计是可爱侧视、身体圆滚滚，但游戏是俯视镜头，玩家只看得到一个个圆背。
- 背上发光的弱点圆圈看起来像眼睛。
- 橙色边缘光把每只虫描成了一个球。

这一轮按俯视镜头重画：身体拉长成头、胸、腹三段，腿向外张开，前端有颚或角，一眼能看出朝向；发光只出现在甲壳缝里。

## 文件

| 文件 | 提示词 | 方法 | 结论 |
|---|---|---|---|
| `a_top.png` / `a_top2.png` | `a_top.txt` | 文生图，key H / F | 不用：画成了圆球加大眼睛的可爱怪 |
| `b_angle.png` | `b_angle.txt` | 文生图，key G | 不用：可爱侧视蚂蚁 |
| `b_angle2.png` | `b_angle.txt` | 文生图，key D | 方向对：俯视、甲壳、缝隙发光。但只有 6 只，种类不全 |
| `c_top_D.png` | `c_top.txt` | 文生图，key D | 风格最好的一张整版；缺飞虫和攻城虫，几只甲虫长得太像 |
| `c_top_H/F/G.png` | `c_top.txt` | 文生图，key H / F / G | 不用：都画成了正面或侧面 |
| `one/1_swarmer.png` … `one/7_queen.png` | `one/*.txt` | 每种一张，key D | **采用**。合成预览图是 `sheet_one.png` |

经验：

- 提示词里提到 Clash Royale 或 Brawl Stars，就会画成可爱风，要去掉。
- 只有 key D 的工作区能稳定画出正俯视。

## 单张结果（`one/`）

| 种类 | 结论 |
|---|---|
| 1 Swarmer | 好：细长、颚明显。头朝下，建模时要转过来 |
| 2 Carapace | 好：宽盾背 |
| 3 Flyer | 好：双翼展开，轮廓独特 |

| 6 Leaper | 好：两侧大镰刀，轮廓最有辨识度 |
| 7 Brood queen | 好：发光的卵囊尾巴 |

## 放宽成“外星异种”（`xeno/`）

主题不变（虫潮防线）。分工如下：

- 小怪和普通怪保持虫形，因为它们靠数量取胜：工蚁、盾甲虫、飞虫、跳虫。
- 精英和 Boss 换成非昆虫的外星物种，从俯视轮廓上就能拉开差别。

提示词要求“好看不恶心”：

- 参考 Overwatch / Destiny / Hades 的怪物设计：造型干净、表面光滑、左右对称。
- 明确排除：黏液滴落、疣、毛、牙、卡通眼、血腥。

每种出两张（`_a` / `_b`），都用 key D。

| 游戏里的种类 | 选用 | 说明 |
|---|---|---|
| snail（攻城） | `4_sieger_b` | 晶刺龟：低矮宽背，长着发光晶柱，四条粗腿。`_a` 的晶刺太少 |
| mold（分裂母体） | `5_jelly_b` | 半透明水母囊，里面有几颗核，正好对应“分裂出孢子”。`_a` 边缘带刺，不透明 |
| spore（分裂出的小个） | `6_spore_a` | 水晶泪滴，内部发光。`_b` 有眯眼，不用 |
| boss | `7_mother_b` 或 `one/7_queen` | `_b` 修长威严，有镰刀臂；旧虫后宽、卵囊发光，缩小后更醒目。`_a` 太像人形，不用 |

`roster.png` 是按游戏里 8 个种类排好的整套预览。

## Tripo 建模（2026-11-02）

- 输入图：在概念图的基础上重画成 3/4 视角，文件是 `tripo/*_in.png`。H2.5 Legacy，每个 15 额度，额度已经用完。
- 原始模型：`tripo/*_raw.glb`。
- 清理：用 `scripts/art/hero_cleanup.py` 减面，结果在 `src/assets/bugs/`。
- 预览：`scripts/art/glb_preview.py` 出俯视图和 3/4 视图，前方放一个小球标出朝向。

| 种类 | 模型 | 结果 |
|---|---|---|
| caterpillar | `swarmer` | 采用 |
| beetle | `carapace` | 采用 |
| locust | `leaper` | 采用（镰刀臂当腿摆） |
| snail | `sieger` | 采用，背上晶柱涂成紫色 |
| boss | `queen` | 不用：像一团花叶，朝向歪、左右不对称。改用代码搭 |

飞虫、分裂母体、孢子没送 Tripo。这几种要透明翅膀、果冻、内部发光，代码做更合适。

拆分和上色见 `src/view/xenos.ts`，说明在 design.md 的“外星异种”一条。
