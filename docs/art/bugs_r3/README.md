# 虫群重设计（第三轮概念）

2026-11-02。旧虫子（`scifi_r2/e_bugs.png`）有三个问题：

- 原设计是可爱侧视、身体圆滚滚，但游戏是俯视镜头，玩家只看得到一个个圆背。
- 背上发光的弱点圆圈看起来像眼睛。
- 橙色边缘光把每只虫描成了一个球。

这一轮按俯视镜头重画：身体拉长成头、胸、腹三段，腿向外张开，前端有颚或角，一眼能看出朝向；发光只出现在甲壳缝里。

## 文件

| 文件 | 提示词 | 方法 | 结论 |
|---|---|---|---|
| `a_top.png` / `a_top2.png` | `a_top.txt` | 文生图，key H / F | 不用：画成了圆球加大眼睛的可爱怪 |
| `b_angle.png` | `b_angle.txt` | 文生图，key G | 不用：可爱侧视蚂蚁 |
| `b_angle2.png` | `b_angle.txt` | 文生图，key D | 方向对：俯视、甲壳、缝隙发光。但只有 6 只，种类不全 |
| `c_top_D.png` | `c_top.txt` | 文生图，key D | 风格最好的一张整版；缺飞虫和攻城虫，几只甲虫长得太像 |
| `c_top_H/F/G.png` | `c_top.txt` | 文生图，key H / F / G | 不用：都画成了正面或侧面 |
| `one/1_swarmer.png` … `one/7_queen.png` | `one/*.txt` | 每种一张，key D | **采用**。合成预览图是 `sheet_one.png` |

经验：

- 提示词里提到 Clash Royale 或 Brawl Stars，就会画成可爱风，要去掉。
- 只有 key D 的工作区能稳定画出正俯视。

## 单张结果（`one/`）

| 种类 | 结论 |
|---|---|
| 1 Swarmer | 好：细长、颚明显。头朝下，建模时要转过来 |
| 2 Carapace | 好：宽盾背 |
| 3 Flyer | 好：双翼展开，轮廓独特 |
| 4 Sieger | **要重画**：没有画出螺旋壳，像一条带条纹的幼虫 |
| 5 Acid blob | **要重画**：长出了腿，变成了半透明背的蜘蛛 |
| 6 Leaper | 好：两侧大镰刀，轮廓最有辨识度 |
| 7 Brood queen | 好：发光的卵囊尾巴 |
