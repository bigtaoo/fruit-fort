# 风格第 4 轮：在圆木墩那张上补围栏

2026-10-29。场地定为草坪 + 圆木墩（第 3 轮）。这轮用图生图（`scripts/art/edit_image.sh`），拿 `base.jpg`（就是 `style_r3/a_logslice.jpg`）当底，只加一圈围栏，试 4 种材质（`*.txt`）。`phone.png` 是缩到 0.3 倍的样子。

图生图把底图保持得很好：镜头、蛋糕、火车、虫子都没变，只多了围栏。比文生图可控得多，后面换东西都用这个办法。

| 文件 | 围栏 | 结果 |
|---|---|---|
| `a_popsicle` | 冰棒棍加红绳 | 和木头轨道同色，缩小后围栏和轨道糊成一条宽木圈。红绳倒是很醒目 |
| `b_marsh` | 粉白棉花糖柱加金色威化横杆 | **最好**。在绿草上最跳，又和轨道分得开。"虫子来啃棉花糖"也说得通，破损就是少几根柱子 |
| `c_blocks` | 彩色积木 | 太花，和红火车、彩色果冻豆抢眼 |
| `d_pretzel` | 椒盐卷饼棍 | 棕色和蚂蚁同色，蚂蚁贴在围栏上就看不见了，蓝甲虫也被挡住 |

## 发现

- **围栏选棉花糖**：粉白在绿草上最清楚，和木头轨道、红火车、深色虫子都分得开。
- **围栏要矮**：几张图里前面那半圈都挡住了轨道（d 最明显）。游戏里镜头更陡，围栏高度控制在轨道宽度的一半左右。
- **围栏和轨道之间要留空**：生图把围栏贴着轨道画了；游戏里轨道半径 2.6、围栏 3.6，中间那一圈草地留着，虫子在那里会被看清。
- **颜色规则**（定下来写进 style-frame）：
  - 地面绿；木头（轨道、木墩）是浅暖木色；
  - 围栏粉白，是全场最亮的"墙"；
  - 虫子深色、饱和（深棕红、蓝紫），不用棕黄、木色，不然会和木头和饼干混在一起；
  - 火车红，英雄靠黑帽认；
  - 弹道和金币用高饱和的彩色，比一切都亮。
