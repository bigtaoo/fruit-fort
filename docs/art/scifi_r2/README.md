## 定调图和现在的引擎差在哪（改场景时对照）

1. **反应堆**：一座**高塔**，大约是轨道半径的 1.5 倍高。白钢外壳，中间是一段青色发光的能量柱，柱外绕一圈浮空光环，底下是八边形台座。现在的引擎版是一个又矮又小的球罩。
2. **磁轨**：一条**宽**环形深色轨道床，两侧是白色边轨，床面上每隔一段有一格青色灯块。比现在的轨道宽一倍左右，是场上最显眼的圆。
3. **护盾墙**：**又高又连贯**。半透明青色的厚板一块接一块围成一圈，板上有裂纹高光；板子之间只露出很窄的深灰色桩子。看上去是一道墙，而不是栏杆。损坏时板子出现裂纹、闪烁，打破后只剩桩子。
4. **地面和外围**：浅冰蓝的地面，上面有大块的裂纹冰板。画面四角是**大块蓝色岩壁**，围成一个盆地，场地有边界、有纵深。没有零散的小石头。
5. **炮车和英雄**：炮车要**大**，英雄的头要从舱口露出来。白色大头盔配紫色面罩，缩小了也能认出来。
6. **虫子**：深紫配黄橙光点，**大小和轮廓差别要明显**。小虫多，有带翅膀的，有甲壳宽的。虫子带深色描边。
7. **画风**：偏卡通着色，有清楚的轮廓线，阴影很淡，整体又亮又干净。泛光只用在反应堆和护盾上。
8. **界面**：深海军蓝的玻璃面板配青色描边，粗体圆角白字。卡片上是彩色大图标，价格用金色。
