# 科幻虫群第 1 轮：定调图

2026-10-31。野餐风偏低龄，和中核加属性的玩法、门户站的主力人群（男性，十几到三十出头）都对不上。立项比较后，owner 选了"科幻轨道炮车对外星虫群"出图。

做法：
- 战斗画面用图生图（`scripts/art/edit_image.sh`），拿现在的实机截图 `base.png`（1280×720 横屏，第一关开局）当底，只换画风。
- 封面用文生图（`generate_image.sh`）。
- 提示词在同名 `*.txt`。
- `phone.png` 是缩到 0.3 倍的对比图，最左是原图。

| 文件 | 地面 / 虫子配色 | 结果 |
|---|---|---|
| `a_desert` | 橙红沙漠，深紫虫，背上有黄橙弱点 | 敌我最分得开：暖地面、青白我方、紫色虫子。氛围最强。围墙块太厚重 |
| `b_moon` | 淡紫灰月面加青绿苔藓，黑绿虫，橙眼 | 虫子最多，虫潮感最足，也最清爽。地面偏冷偏灰，略显平淡 |
| `c_base` | 圈内是金属六边形甲板，圈外是黄褐沙漠，暗红虫 | 半透明能量盾板最好看，基地感强。黄色警示条和金属地面让画面偏杂 |
| `d_desert2` | 同 a，提示词更强调"保持原构图" | 界面位置保留得最好，配色和 a 一致 |
| `thumb` | 门户封面 | 最像主流爆款：Q 版陆战队员、白青炮车、戴王冠的巨型虫后、金币和爆点。可爱又热闹 |

## 发现

- **画风方向成立**：明亮饱和的风格化 3D（皇室战争、荒野乱斗那一路）放在这个题材上，第一眼就比野餐版"主流"得多。缩略图的吸引力差距最明显。
- **配色**：橙红地面 + 青白我方 + 深紫虫（a、d、封面）敌我最清楚，缩到手机大小也认得出。建议以它为基准。
- **构图没保住**：四张战斗图都把炮车（或英雄）放到了正中间，代替了能源核心，轨道也丢了。生图模型把"中心的东西"和"主角"合成了一个。所以这轮只能用来定画风和配色；"核心在中间、炮车在轨道上绕"要等进引擎里验证。
- 生图里的界面文字都是乱码，只看位置和面板样式。

## 进引擎后改地面（2026-10-31）

owner 觉得橙红地面太深太重，地面改成了浅冰蓝。截图是 `engine_frost_{d,p}.png`。紫色虫子和橙色弱点在浅蓝上更醒目，青色护盾和轨道靠深色轨道底座也还看得清。沙漠版截图是 `engine_{d,p,l}.png`，加 `?ground=sand` 可以切回去对比。
