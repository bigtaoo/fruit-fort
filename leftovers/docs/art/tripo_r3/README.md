## 发现

- **5 个都一次成功**，没有重来。每个生成约 2 分钟，导出约 10 秒。
- **积分**：110 → 35。导出：5 → 0。
- **设置会记住**：H2.5、关贴图、三角面、面数这些设置换图后保留，只有面数要按模型改。面数要在输入框里改，按回车会把面板关掉、值没存上；改完按 Tab 才生效。
- **朝向**：火车最长的是 x 轴（车头朝 -x 还是 +x 进游戏时再看），三个英雄是站立的、y 最高，蛋糕是圆的。
- **英雄要能互相认出来**：锡兵细高、机器人方、恐龙胖圆，轮廓本身就分得开；黑帽在游戏里另外加。
- **总量**：三轮 10 个模型合计约 0.3 MB，离 §16.3 的 2 MB 很远。
