# 风格第 2 轮：不用格子布，场地和画风一起发散

2026-10-29。第 1 轮的四张图都成了同一种柔和 3D，所以这轮把风格描述放在最前面，场景描述精简（`*.txt`）。每张换一种场地，火车选和场地拉开的颜色。`phone1.png`、`phone2.png` 是缩到 0.3 倍的样子（`scripts/art/phone_view.py`）。

| 文件 | 场地 | 画风 | 结果 |
|---|---|---|---|
| `a_table` | 木头花园桌 | 3D 玩具 | 蓝色把整张图都染了：蛋糕、围栏、车厢全是蓝的。木桌本身看着舒服，但虫子几乎没画出来 |
| `b_lawn` | 修剪过的草坪，蛋糕放在树桩上 | 明亮 3D | 红火车压在绿草上非常跳，锡兵的黑帽也清楚。树桩让蛋糕变高，从斜上方看会挡住后面半圈。没画围栏 |
| `c_bedroom` | 儿童房地板上的圆形地图地毯 | 温暖 3D | "玩具守自己的房间"这个设定最顺。但地毯上的道路图案太花，蚂蚁混在里面找不到 |
| `d_night` | 夜晚野餐，灯笼和串灯 | 暗调 3D | 氛围最强。蛋糕和蜡烛是全场最亮的地方，正好是要守的东西；发光的弹道会很显眼。虫子在暗处只剩发光的眼睛，要靠轮廓光才认得出 |
| `e_paper` | 薄荷绿波点纸 | 纸艺立体书 | 画面最干净，红火车配黑帽一眼就认出。忘了画蛋糕。纸艺是平面加硬投影，用代码最好做，模型也最省 |
| `f_book` | 浅黄碎花桌布 | 水粉彩铅绘本 | 最有个性。但这是 2D 手绘的质感，3D 模型很难做出来；要走这条路，整个游戏就得改成 2D |

## 发现

- 风格放到提示词最前面以后，画风终于拉开了（d、e、f 明显不一样）。代价是场景内容会丢：e 没有蛋糕，b 没有围栏。
- **场地颜色**：绿色（草坪）和浅色纯色（纸、桌布）都能把红火车和深色虫子衬出来，比红白格子好得多。花纹要小、要淡，c 的地图地毯就是反例。
- **场地都能用代码做**：草坪、纯色纸、木纹板都比格子布简单，不影响"场地留程序"的路线。
- 想到的几个题材方向：
  - **草坪野餐**（b）：保留野餐题材，只把布换成草地，或者在草地上铺一块小一点、颜色淡的布。
  - **儿童房**（c）："玩具守护生日蛋糕"更顺理成章，Logo 和故事也更好讲。地毯要换成纯色或大块图案。
  - **夜晚**（d）：可以当第 2 章或者 Boss 关的换皮，不适合当主画面，太暗。
  - **纸艺**（e）：画风上最省事、手机上最清楚，但"玩具"的感觉弱了一些。
