## 发现

- **一律避开绿色**：草地是全场最大的一块颜色，绿色的虫子（第一版的蝗虫）在手机上就看不见了。霉菌团也偏绿，勉强能看出来。以后加虫子先看 `on_grass.png` 这种对照。
- **蝗虫画了 3 版**（旧版都在 `old/`）：
  - 第 1 版墨绿色，融进草地；
  - 第 2 版黑底黄条纹，看得清，但圆肚子加条纹、翅膀张开，像马蜂，会和以后的"蜂后" Boss 撞在一起；
  - 第 3 版把"巨大的弯折后腿"放在提示词最前面，写明翅膀收起来、不要条纹、不要圆肚子（"Not a bee, not a wasp"），这才像蚱蜢。
  - **结论**：提示词里写明"不要像什么"有用。`phone3.png` 是第 3 版的对照图。
- **这一轮的 key 问题**：key D 返回"API budget exhausted"，原来的切换脚本只认"rate limit"，遇到这个就直接报错退出。`mistral_failover.sh` 已改成遇到预算用完就马上换下一个 key，所有 key 都用完了才放弃。
- 金甲虫（§6 随机事件）不在 P0 清单里，没有出图；需要时用甲虫的提示词，换成金色就行。
