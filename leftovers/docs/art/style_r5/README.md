# 风格第 5 轮：草坪换野餐布

2026-10-30。草地占了画面一半以上的三角形和大部分 draw call，却只是装饰（§16.18 三角形预算），所以试把棋盘放到野餐布上。用图生图（`scripts/art/edit_image.sh`），拿 `base.png`（就是 `style_r4/b_marsh.png`）当底，只换地面，树桩换成蛋糕盘。第 4 轮不用布的理由是“红白格子会把红火车和深色虫子吃掉”，所以这轮不用红色，三块都是低对比的布（`*.txt`）。`phone.png` 是缩到 0.3 倍的样子，最左是原图。

| 文件 | 布 | 结果 |
|---|---|---|
| `a_blue` | 淡蓝米白大格子 | 最清爽，红火车和粉围栏在冷色上最跳。生图把蚂蚁弄丢了，看不出虫子在蓝格上清不清楚 |
| `b_yellow` | 奶黄米白大格子 | 最像野餐，深色蚂蚁在浅黄布上最清楚。暖色多了：金色威化横杆、奶油蛋糕和布都是黄的，略糊在一起 |
| `c_mint` | 薄荷绿素布、小白花 | 最安静。颜色太接近草地，布和草分不太开 |

## 发现

- 三张图里布都只比围栏大一圈，四周还是一大片草。生图没有按提示让布铺满画面。游戏里布外那圈草离镜头远，可以只用贴图，不放 3D 草。
- 蛋糕盘比树桩干净，蛋糕更突出。
- 生图都把蓝色甲虫弄丢了，部分蚂蚁画在围栏里面，不能据此判断甲虫的可读性。
