# 风格第 1 轮：四个方向的文生图

2026-10-29。用 `scripts/art/generate_image.sh`（从 standing 搬来，Mistral 图像代理）出图，提示词是 `style-frame.md` §7 的场景描述，后面各加一句风格描述（`*.txt`）。

| 文件 | 想要的方向 |
|---|---|
| `a_diorama` | 柔和 3D 玩具微缩景观，暖阳，无描边 |
| `b_toon` | 卡通着色加粗描边，单层硬阴影 |
| `c_clay` | 黏土定格动画 |
| `d_craft` | 手工玩具：木头小人、毛毡、缝线 |

`phone.png` 是四张图缩到 0.3 倍的样子（蛋糕约 105 像素宽，和竖屏手机上一样大），由 `scripts/art/phone_view.py` 生成。

## 发现

- **风格那一句几乎没起作用**：四张图都是同一种柔和 3D 渲染，b 没有描边，c 也不像黏土。场景描述太长，把风格压住了。下一轮要把风格放在最前面，场景描述精简。
- **画幅固定 1152×896**：要竖屏也给横图。竖屏定调图只能从横图里裁，或者改用图生图（`edit_image.sh`）拿竖屏截图当底。
- **能用的东西**：
  - 深棕红的蚂蚁在红白格子上，缩到手机大小也看得出，是一个个深色小点。
  - 锡兵的黑色高帽是最好认的特征，缩小后还在。
  - 甲虫用蓝紫色、蜗牛用棕色壳，轮廓都清楚。
  - 棉花糖围栏（b、c）的形状好认。c 那种连成一圈的矮墙比一根根柱子更像"围栏"。
- **问题**：
  - **红火车放在红格子布上会糊**（b、d 最明显）。火车或者布要换颜色：火车换蓝或绿，或者布换成别的颜色的格子。
  - a 的草地和暖阳氛围最好，但游戏里看不到布外面。
  - 生图会自己加东西：c 有两个车头，d 的锡兵被画成了车厢。设定图要一个角色一张。
